# 🚀 PrepAI – AI Interview Question Generator

PrepAI is an interactive web tool designed to generate tailored interview questions and preparation prompts for various roles and tech stacks.

---

## ✨ Features
* **Role-Based Question Generation:** Generates interview questions tailored to specific job domains.
* **Modern & Responsive UI:** Clean interface built with semantic HTML and styled with modern CSS.
* **Fast & Lightweight:** Built using pure vanilla JavaScript without bulky frameworks.

---

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and layout
* **CSS3:** Styling and modern UI components
* **JavaScript (ES6+):** Dynamic logic and question generation handling
